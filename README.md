# MedicalPortal — Медицинский портал (ASP.NET Core 8 MVC + SQLite)

Учебный и практический веб-проект на **ASP.NET Core 8 MVC** с базой данных **SQLite** (Entity Framework Core) и системой аккаунтов врачей.

## Реализованные задания (ООП)

1. **Задание №1 — Класс `Neurologist`** (`Models/Neurologist.cs`)
   - Наследуется от абстрактного класса `Doctor`, принимает имя и стаж врача.
   - Реализует метод `Reception()`, возвращающий сообщение: `«Невролог проводит проверку нервной системы»`.
2. **Задание №2 — Свойство `Specialization`** (`Models/Doctor.cs`)
   - В абстрактный класс `Doctor` добавлено `public abstract string Specialization { get; }`.
   - Свойство реализовано в классах `Therapist`, `Cardiologist`, `Dentist` и `Neurologist`.
3. **Задание №3 — Класс `Patient`** (`Models/Patient.cs`)
   - Свойства `Name`, `Age`, `Diagnosis` и метод `ShowPatientInfo()`.
4. **Задание №4 — Класс `Appointment`** (`Models/Appointment.cs`)
   - Связь пациента и врача, дата приёма `AppointmentDate` и метод `ShowAppointment()`.
   - Вымышленные начальные данные автоматически заполняются при запуске (`Data/DbInitializer.cs`).

## Возможности портала

- **Аккаунты врачей и профильные диагнозы**: регистрация новых врачей с выбором специальности, логина/пароля и диагноза, который ставит врач; вход в личный кабинет (`Cabinet`), проведение приёма (`Reception()`) и постановка диагноза пациенту.
- **Фильтрация**:
  - **Врачи**: по специальности, профильному диагнозу, минимальному стажу и поиску.
  - **Пациенты**: по диагнозу, возрасту (от/до) и поиску, а также карточка пациента с полной историей приёмов.
  - **Записи на приём**: по специальности, врачу, диагнозу, статусу, имени пациента и датам (от/до), с проверкой пересечения времени и возможностью переноса/отмены.

## Как запустить локально

1. Установить **.NET 8 SDK**.
2. Открыть `MedicalPortal.sln` в Visual Studio или перейти в папку проекта в терминале.
3. Запустить проект:

```bash
dotnet run
```

4. Открыть в браузере `http://localhost:5194` (или `https://localhost:7083`).
