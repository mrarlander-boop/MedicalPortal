# MedicalPortal — Clinic Management Web App (ASP.NET Core 8 MVC + SQLite)

Веб-приложение для управления клиникой на **ASP.NET Core 8 MVC** с базой данных **SQLite** (Entity Framework Core 8), авторизацией врачей и многокритериальной фильтрацией записей.

## Архитектура и возможности

- **ООП и паттерны проектирования (`Models/`, `Services/`):**
  - Иерархия врачей на базе абстрактного класса `Doctor` (`Therapist`, `Cardiologist`, `Dentist`, `Neurologist`) и фабрика `DoctorFactory`.
  - Безопасное хеширование паролей через `PasswordHelper` и аутентификация на базе Cookie (`CookieAuthenticationDefaults`).
- **Слой данных (`Data/`):**
  - `MedicalDbContext` (Entity Framework Core `8.0.11` + `Microsoft.EntityFrameworkCore.Sqlite`).
  - `DbInitializer` — автоматическая инициализация БД и сидинг стартовых данных при первом запуске.
- **Функционал портала (`Controllers/`, `Views/`):**
  - **Аккаунты врачей и личный кабинет (`AccountController`, `CabinetController`):** регистрация врача со специализацией и профильным диагнозом, вход, проведение приёма.
  - **Врачи (`DoctorsController`):** фильтрация по специальности, профильному диагнозу, минимальному стажу и текстовому поиску.
  - **Пациенты (`PatientsController`):** карточки пациентов с историей приёмов, фильтрация по диагнозу, возрасту и поиску.
  - **Записи на приём (`AppointmentsController`):** фильтрация по врачу, специальности, статусу, пациенту и диапазону дат, проверка пересечений по времени, перенос и отмена приёма.

## Локальный запуск

1. Установите **.NET 8 SDK**.
2. Склонируйте репозиторий и выполните в корне проекта:

```bash
dotnet run
```
